# v0.6 Public Working Manuscript

This release contains the v0.6 public working manuscript for **Context Is Not Control: Source-Boundary Failures in LLM Evidence Use**, together with cleaned lite replication packages for the open-weight and frontier/API experiments.

Included files:

- `Context_Is_Not_Control_v0_6.pdf`
- `context_is_not_control_open_weight_replication_package_v0_2_LITE_no_raw_or_heavy_outputs.zip`
- `context_is_not_control_frontier_api_replication_package_v0_2_LITE_no_raw_outputs.zip`

The lite packages exclude raw/heavy model-output files. Full archives are preserved separately.
